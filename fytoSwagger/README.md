# Prime Wave Swagger API Documentation

This repository contains the interactive Swagger/OpenAPI documentation for the Prime Wave backend.

## How to View Locally
Simply open the `index.html` file in any modern web browser (e.g. Google Chrome). It will pull Swagger UI resources via CDN and render `swagger.json` automatically.

## How to Deploy to GitHub Pages
1. Push this repository to GitHub at `https://github.com/fytomail/fytoSwagger`.
2. Go to Repository **Settings** -> **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your interactive Swagger UI will be live online!
